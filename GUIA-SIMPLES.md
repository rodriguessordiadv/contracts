# 🎯 Guia Super Simples — Sávio & Juliana

> Pra quando você não está a fim de ler manual. Só o essencial.
> Se você tem quinze anos e sabe mandar mensagem no WhatsApp, você sabe usar isto.

---

## 🚀 Como funciona (em uma frase)

Você **pede em português normal** — como se estivesse falando comigo — e eu **faço o documento pronto** no padrão da casa. É só pedir.

---

## 👥 O que cada um faz

### Sávio — Advogado & Contador
- Precisa de peça jurídica → pede pra mim.
- Precisa de coisa contábil (IRPF, Nibo, certificado) → pede pra mim.

### Juliana — Advogada, sócia
- Precisa de peça jurídica → pede pra mim, mesmo fluxo do Sávio.
- Se for algo contábil → avisa o Sávio.

Regra: **jurídico e contábil usam o mesmo jeito de pedir.** Muda só o assunto.

---

## ⚖️ JURÍDICO (Sávio & Juliana)

| Preciso de... | O que fazer |
|---|---|
| Petição inicial | Manda os dados → sai pronta no padrão R&S |
| Contestação | Mesma coisa |
| Agravo urgente | Sai pronto — **⚠️ depois você clica "urgente" no portal, na mão** |
| Laudo previdenciário | Sai completo (laudo + documentos) |
| Cobrança de honorários | Manda um resumo das peças → calculo horas + valor |
| Contrato | Me diga o número **CNTR** e sai formatado |

**Padrão da casa:** Book Antiqua, cabeçalho institucional R&S, bonito e profissional. Você não precisa formatar nada.

---

## 🧮 CONTÁBIL (Sávio)

| Preciso de... | O que fazer |
|---|---|
| IRPF (Imposto de Renda) | Manda os dados → você preenche na Receita Federal |
| Diagnóstico (cliente devendo) | Varro tudo → trago plano + valor |
| Certificado digital | Trato pagamento + documentos, tudo |
| Tarefa no Nibo | Manda título + descrição + responsável |
| Procuração e-CAC (RFB) | Se pessoa falecida ou incapaz, trato o caso especial |
| Cadastro no eSocial | Coleta guiada, passo a passo |

## 📅 Antes de criar evento no calendário — confirme qual

| Calendário | Pra quê |
|---|---|
| R&S Adv | Reuniões jurídicas (Sávio & Juliana) |
| RadéC | Reuniões contábeis |
| iCT Edu | Aulas de inglês / espanhol |
| Pessoal | Compromissos do Sávio |

**Regra de ouro:** na dúvida, pergunta qual calendário **antes** de colocar no sistema.

## 💬 Como pedir — 3 jeitos (todos funcionam)

**Jeito 1 — Direto**
```
"Faz uma petição"
"Preciso do IRPF"
"Cobrança de honorários deste mês"
```

**Jeito 2 — Com detalhes (sai melhor)**
```
"Petição inicial, cliente Pet Barber, aluguel comercial"
"IRPF do João Silva, autônomo, 2025"
"Laudo previdenciário do cliente Bruno"
```

**Jeito 3 — Preguiçoso (também vale)**
```
"Ativa rs-advogados"
"Roda IRPF"
"Manda tarefa no Nibo"
```

---

## ⚠️ Não esquecer

1. **Urgente no TJRS** → eu aviso quando está pronto, **mas você clica "urgente" no portal, na mão.**
2. **Calendário** → confirme qual antes de colocar.
3. **WhatsApp jurídico** → tom profissional, sem emoji e sem brincadeira.
4. **Prazos** → me pergunta "tá vencendo alguma coisa?" e eu te aviso.
