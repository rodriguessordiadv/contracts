# Templates de Texto Prontos para Procuração e-CAC

Textos prontos para colar em cada campo da Receita. **Todos sem acentos** (regra do sistema).

---

## Template 1 — Descrição do Processo Digital

Vai no campo "Descrição" da tela de Solicitar Serviço. Personalizar entre `[colchetes]`.

### Para falecido com inventário extrajudicial em curso

```
Cadastramento de procuracao digital para acesso ao e-CAC em nome do
espolio de [NOME COMPLETO DO FALECIDO] (CPF [XXX.XXX.XXX-XX]),
falecido(a) em [DD/MM/AAAA], sendo o requerente [NOME COMPLETO DO PROCURADOR]
(CPF [XXX.XXX.XXX-XX]) o inventariante nomeado por escritura publica
lavrada no [N° TABELIONATO DE NOTAS DE PORTO ALEGRE/RS], Livro [N°], fls [N°],
em [DD/MM/AAAA].
```

### Para falecido com inventário judicial em curso

```
Cadastramento de procuracao digital para acesso ao e-CAC em nome do
espolio de [NOME COMPLETO DO FALECIDO] (CPF [XXX.XXX.XXX-XX]),
falecido(a) em [DD/MM/AAAA], sendo o requerente [NOME COMPLETO DO PROCURADOR]
(CPF [XXX.XXX.XXX-XX]) o inventariante nomeado nos autos do processo de
inventario n° [NUMERO DO PROCESSO], em tramite na [VARA/COMARCA].
```

### Para falecido sem bens (inventário negativo)

```
Cadastramento de procuracao digital para acesso ao e-CAC em nome do
espolio de [NOME COMPLETO DO FALECIDO] (CPF [XXX.XXX.XXX-XX]),
falecido(a) em [DD/MM/AAAA], sem bens a inventariar, sendo o requerente
[NOME COMPLETO DO HERDEIRO] (CPF [XXX.XXX.XXX-XX]) [meeiro/herdeiro] legitimo,
conforme Declaracao de Inexistencia de Bens a Inventariar ou Arrolar anexa.
```

### Para incapaz

```
Cadastramento de procuracao digital para acesso ao e-CAC em nome de
[NOME COMPLETO DO TUTELADO/CURATELADO] (CPF [XXX.XXX.XXX-XX]),
sob [tutela/curatela] do requerente [NOME COMPLETO DO TUTOR/CURADOR]
(CPF [XXX.XXX.XXX-XX]), conforme [termo de tutela/sentenca de curatela]
registrado(a) no [CARTORIO], em [DD/MM/AAAA].
```

### Para menor de idade

```
Cadastramento de procuracao digital para acesso ao e-CAC em nome de
[NOME COMPLETO DO MENOR] (CPF [XXX.XXX.XXX-XX]), nascido(a) em
[DD/MM/AAAA], representado(a) por seu(sua) [pai/mae/responsavel legal],
o(a) requerente [NOME COMPLETO] (CPF [XXX.XXX.XXX-XX]).
```

### Para pessoa sem gov.br ouro/prata

```
Cadastramento de procuracao digital para acesso ao e-CAC em nome de
[NOME COMPLETO DO OUTORGANTE] (CPF [XXX.XXX.XXX-XX]), que nao possui
conta gov.br nivel ouro ou prata, estando impedido(a) de cadastrar a
Autorizacao de Acesso diretamente no Portal de Servicos ou e-CAC.
Procurador outorgado: [NOME COMPLETO] (CPF [XXX.XXX.XXX-XX]).
```

## Template 2 — Título dos Anexos

Cada anexo no formulário pede um **Título**. Sempre sem acentos, curto, descritivo.

### Para o Campo A (Procuração assinada)

```
Procuracao RFB [Nome Curto] assinada
```

Exemplos:
```
Procuracao RFB Vera assinada
Procuracao RFB Jose assinada
Procuracao RFB Maria Joao Silva assinada
```

## Template 3 — Nomenclatura de Arquivos

**Permitido:** letras, números, espaço, hífen (-), underscore (_).
**Proibido:** acentos (á é í ó ú â ê ô ã õ), cedilha (ç), barras (/ \\), aspas, símbolos.

### Padrão recomendado (sem underscore, com espaços)

```
procuracao RFB [Nome] assinada.pdf
obito [Nome].pdf
Escritura Nomeacao Inventariante.pdf
Termo Inventariante Judicial.pdf
Termo Curatela [Nome].pdf
Termo Tutela [Nome].pdf
Certidao Nascimento [Nome].pdf
Sentenca Interdicao [Nome].pdf
Declaracao Inexistencia Bens.pdf
Certidao Inventario Negativo.pdf
RG [Nome Procurador].pdf
CNH [Nome Procurador].pdf
OAB [Nome Procurador].pdf
```

### Tabela de substituição de acentos

| Original | Substituir por |
|----------|----------------|
| á â ã | a |
| é ê | e |
| í | i |
| ó ô õ | o |
| ú | u |
| ç | c |
| Á Â Ã | A |
| É Ê | E |
| Í | I |
| Ó Ô Õ | O |
| Ú | U |
| Ç | C |

## Template 7 — Declaração de Inexistência de Bens a Inventariar

Para casos de inventário negativo, baixar o modelo oficial da Receita:

```
https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/formularios/modelos/anexo-ix.pdf
```

Modelo do texto (caso prefira reescrever):

```
DECLARACAO DE INEXISTENCIA DE BENS A INVENTARIAR OU ARROLAR

Eu, [NOME COMPLETO], [nacionalidade], [estado civil], [profissao],
portador(a) do RG n° [XXXX] e CPF n° [XXX.XXX.XXX-XX], residente e
domiciliado(a) em [endereco completo], na qualidade de [meeiro(a) /
herdeiro(a)] legitimo(a) de [NOME COMPLETO DO FALECIDO], inscrito(a) no
CPF n° [XXX.XXX.XXX-XX], falecido(a) em [DD/MM/AAAA], conforme Certidao
de Obito [matricula], DECLARO, sob as penas da lei, que a pessoa
falecida acima identificada NAO DEIXOU BENS A INVENTARIAR OU ARROLAR
em seu patrimonio, motivo pelo qual nao houve abertura de processo de
inventario.

A presente declaracao e feita para fins de cadastramento de procuracao
digital para acesso ao e-CAC da Receita Federal do Brasil, nos termos
da legislacao aplicavel.

[Cidade], [DD] de [mes por extenso] de [AAAA].

___________________________________________
[NOME COMPLETO DO DECLARANTE]
CPF: [XXX.XXX.XXX-XX]
```

## Template 8 — Modelo de Atualização Cadastral de CPF (se necessário antes)

Se o CPF do falecido ainda está como "Pendente de Regularização" (não convertido para "Titular Falecido"), abrir processo separado **antes** da procuração:

**Caminho:** e-CAC → Cadastros → CPF → Atualização Cadastral
**Ou:** Requerimentos Web → Cadastros → Atualizar Dados de CPF

**Descrição do processo:**
```
Atualizacao cadastral de CPF para registro de obito de [NOME COMPLETO]
(CPF [XXX.XXX.XXX-XX]), falecido(a) em [DD/MM/AAAA], conforme Certidao
de Obito anexa. Requerente: [NOME] (CPF [XXX.XXX.XXX-XX]), [parentesco]
do(a) falecido(a).
```

**Anexos:**
- Certidão de óbito
- RG do requerente
- Documento que comprove parentesco (certidão de nascimento, casamento, ou escritura de inventariante)
