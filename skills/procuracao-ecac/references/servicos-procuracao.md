# Serviços do e-CAC por Perfil Tributário do Outorgante

Lista completa dos serviços disponíveis na Procuração Digital, segmentada por perfil tributário do outorgante. A skill consulta esta referência para gerar a lista de marcação personalizada.

---

## Estratégia de Apresentação ao Usuário

**Regra de ouro:** se a lista de serviços a marcar tem mais de 30 itens, **inverte a entrega** — apresenta a lista de **exclusão** ("marca tudo e desmarca estes"), que é mais curta. Para listas pequenas, apresenta como "marca estes".

**Sempre apresenta na ORDEM em que os serviços aparecem na tela do Sistema de Procurações RFB**, agrupados nos 3 blocos:
1. Destinados a Pessoa Física
2. Destinados a Pessoa Jurídica
3. Destinados tanto a Pessoa Física quanto a Pessoa Jurídica

---

### Perfil B — PF Autônoma (com CAEPF / ISS Municipal)

Outorgante é/era profissional autônomo:
- Advogado, médico, engenheiro, arquiteto, contador, dentista etc.
- Tem inscrição no CAEPF (antiga matrícula CEI)
- Tem inscrição municipal de ISS (autônomo)
- Pode ter empregador doméstico

## Lógica de Decisão para o Claude

Quando o usuário pede "marca tudo pra mim" sem especificar perfil:

1. **Pergunta o mínimo essencial:**
   - "O outorgante era apenas pessoa física comum, ou também tinha CNPJ / autonomia / imóvel rural?"
2. **Se a resposta envolve PJ ou autônomo, oferece a **lista de exclusão**:**
   - "Marca tudo e desmarca estes [N itens]"
3. **Se a resposta é PF pura, lista os ~34 serviços positivamente.**
4. **Se o usuário tem pressa ou diz "marca tudo":** entrega só a lista de exclusão dos `Serviços que NUNCA marcar`. Cobre todos os perfis em uma só lista.

| Perfil do outorgante | Quantos a marcar | Estratégia |
|---|:---:|---|
| Pessoa idosa comum (só aposentadoria, sem trabalho ativo) | 34 | Lista positiva (Perfil A) |

| Médico autônomo + ISS POA | ~50 | Lista de exclusão (Perfil B) |
| Comerciante sócio de Ltda (Simples) | ~95 | Lista de exclusão (Perfil C+D) |
| Empresário Lucro Presumido | ~95 | Lista de exclusão (Perfil C+E) |
| MEI sapateiro | ~70 | Lista de exclusão (Perfil C+F) |
| Sitiante (PF + ITR) | ~37 | Lista positiva (Perfil A+G) |
| Pessoa com perfil misto (PF + ex-PJ + ex-MEI) | ~110 | Lista de exclusão (todos) |
