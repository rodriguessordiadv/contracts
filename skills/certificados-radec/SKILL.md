## Observações Críticas

I. **Certificados são sempre 1 ano** — nunca ofereça 3 anos, não existe operacionalmente.

II. **O Sérgio é novo** — sempre suavizar a introdução dele na mensagem ao cliente, explicar que é parceiro novo e melhor que os anteriores.

III. **Já pagamos antecipado** — mencionar sempre que a RadéC já cobriu o custo com o fornecedor, o que agiliza tudo.

IV. **Horários especiais** — o Sérgio oferece flexibilidade se o cliente precisar de algo urgente.

V. **Todos os números devem ser clicáveis** — colocar no formato **+55 [DDD] [9][NNNN]-[NNNN]** para ser reconhecido automaticamente como link pelo WhatsApp.

VI. **Painel sempre atualizado** — após cada entrega, incluir cliente no painel com status e datas.
